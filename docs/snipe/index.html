Forge Hammer, with a snipe box

A modified version of the Forge Hammer browser extension for Forge of Empires. When you open another player's Great Building, it tells you which spot to take for the most Forge Point profit, and exactly how many FP to put in.

Download for Chrome / Edge

A .zip file. No GitHub account needed.

Best snipe
#1425 FP+145 FP
Example: click the FP amount to paste it into the game

What the box shows

The place you can lock so nobody below can overtake you, the FP that takes, and your profit after your own Arc bonus. If you can't afford the best spot, it shows the best one you can afford. It also warns you when taking the spot would level the building.

How to install

  1. If you already have Forge Hammer installed, remove it first so the two don't both run.
  2. Download the zip above and extract it somewhere it can stay, like your Documents folder. Chrome loads it from there every time, so don't delete or move it later.
  3. In Chrome, go to chrome://extensions (in Edge, edge://extensions).
  4. Turn on Developer mode.
  5. Click Load unpacked and choose the foe-main folder you extracted. It's the one with manifest.json directly inside it, not a folder within it.
  6. Reload your Forge of Empires tab, then open someone's Great Building.

Chrome may show a notice about developer-mode extensions when it starts. That's normal for extensions installed this way.

Updating

This version doesn't update itself. To get a newer one, download the zip again, replace the old folder with the new one, and click the reload arrow on the extension in chrome://extensions.
